Every data source—built-in feed or plugin—is configured in one place: the Configuration tree. Connect a source and its data appears live on the map as entities, ready to inspect, correlate, and share.

Never added a source before? The [Getting Started](/docs/operator) quick start puts live demo data on the map in 60 seconds.

## How Every Source Works

All sources follow one pattern:

1. Press `Ctrl+K` (or `⌘+K` on macOS) and select **Configuration**. The tree groups sources by category—**Feeds**, **Network**, **Vehicles**, **Cameras**, **Plugins**—and the sidebar search filters it.
2. Select the source and click **Add**, then pick the connection type—each shows a short description of what it does—and fill in the settings.
3. Click **Apply Configuration**. Changes take effect live: a **Config applied** toast confirms the source picked them up, and it shows an **Active** badge.

Add as many instances of a source as you need—several AIS receivers, multiple ADS-B pollers over different regions.

Sources delivered by [plugins](/docs/operator/plugins) are even simpler: they're pre-listed under **Plugins**—just flip **Enabled** on.

## Verify It's Flowing

- The source's row shows an **Active** badge (green). **Failed** or **Conflict** (red) means something needs attention—check its settings.
- Select the source and open its **Metrics** tab for live throughput—ADS-B, for example, shows aircraft tracked and entities pushed.
- Entities land on the map and in the entity list within seconds of applying.
